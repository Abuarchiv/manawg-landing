# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report privately through
[GitHub's private vulnerability reporting](https://github.com/Abuarchiv/manawg/security/advisories/new)
of the app repository and say that the report is about the website, or write to info@manawg.com.
Include what is affected, how to reproduce it and what an attacker could do with it.

ManaWG is maintained by one person. You can expect an acknowledgement within 7 days and a first
assessment within 14 days.

## Scope

- This repository and the site it builds, [manawg.com](https://manawg.com).
- The app at app.manawg.com is covered by the
  [app repository's policy](https://github.com/Abuarchiv/manawg/blob/main/SECURITY.md).
- Not in scope: denial of service through traffic volume. Do not run automated scans against
  manawg.com.

## Supported versions

Only the latest commit on `main` and the deployment built from it are supported.
